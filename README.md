# Nortic Newsletter Form :love_letter:
This is the monorepo for the Nortic Newsletter Form.
This module allows you to embed a subscription form for your newsletters created with Nortic Insight! It consists of 2 packages:

## Core package
The core package is a Javascript module to inject the newsletter form into your applications.
For more information, refer to the package [README](https://github.com/nortic-ab/newsletter-form/tree/main/packages/newsletter-subscription)

## Vue package
The Vue package is a Vue-wrapper of the core package.
For more information, refer to the package [README](https://github.com/nortic-ab/newsletter-form/tree/main/packages/newsletter-subscription-vue)
